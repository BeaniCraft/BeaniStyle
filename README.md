## Extras
BeaniStyle contains extra/alternative assets, which you can find in the `"BeaniStyle/Extras"` folder.  
Here's everything in the extras folder:

* Hit Explosions <small>(`"Explosion.png"`)</small>
* Good Judgement <small>(`"Judge.png/Judge_ja.png"`)</small>
* Green KA-DONs <small>(`"Swap.png"`)</small>
* Combo Voice Lines <small>(`"Combo"`)</small>
* Hit Sounds <small>(`"BeaniStyle"`)</small>

(See [Installation Guide.md](https://github.com/BeaniCraft/BeaniStyle/blob/main/Extras/Installation%20Guide.md) for details on how to install these assets.)
